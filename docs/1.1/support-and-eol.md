# Support lifecycle

KITPro Linux Server 1.1 has a planned standard-support period of 12 months from
its eventual publication date. The publication and end-of-support dates remain
unset until public release approval.

If publication occurs on November 1, 2026, the proposed support window is
November 1, 2026 through November 1, 2027. The actual publication record
controls these dates.

Linux 1.0 installations at supported production generation `1.0-g0002` may use
the documented 1.0-to-1.1 transition after the 1.1 repository is published and
promoted. KITPro Console has its own application lifecycle and remains optional.
